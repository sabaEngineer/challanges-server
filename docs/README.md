# Documentation

## Structure

```
docs/
├── README.md                  -- You are here
├── features/                  -- Feature documentation (updated with each new feature)
│   └── auth.md                -- Authentication (Google OAuth + JWT)
└── todo/                      -- Pre-production tasks and setup guides
    ├── pre-release-checklist.md           -- Everything to do before going live
    ├── google-oauth-android-setup.md      -- Android Google Sign-In setup guide
    └── google-oauth-ios-setup.md          -- iOS Google Sign-In setup guide
```

## How to Use

- **`features/`** -- When a new feature is built, add a documentation file here explaining how it works, its API endpoints, file structure, and any important details. This is the living documentation of the project.

- **`todo/`** -- Pre-production checklists and setup guides. Things that need to be done before releasing to the app stores. Check items off as you complete them.
